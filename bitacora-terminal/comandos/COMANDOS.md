pwd: muestra la ruta completa, para saber donde estas parado
ls: muestra los archivos visibles de una capeta, bueno en la carpeta que estas en ese momento
cd: sirve para cambiar de directorio
mkdir: sirve para hacer/crear un nuevo directorio
touch: sirve para hacer un archivo
cat: muestra el contenido de un archivo de texto, creo que tambien sirve para concatenar
tree: sirve para mostar como estan los directorio, como estan ordenados creando un arbol/ramas
man: es el manual de usuario, se puede presionar h para ayuda o q para salir
history: es literalmente el historial de todo lo que haya ocurrido
